## Project Overview

TourEase is a Tourism Management System designed to simplify travel planning and management. The platform provides users with hotel booking services, tour guide reservations, travel package selection, search functionality, and personalized user dashboards.

## Features

### Authentication Module
- User Registration
- User Login
- Logout

### Hotel Booking Module
- Hotel Listing
- Hotel Details and Booking

### Tour Guides Module
- Tour Guide Listing
- Tour Guide Booking

### Travel Packages Module
- Package Listing
- Cart and Checkout

### Search Module
- Search and Filter Functionality

### User Dashboard
- Dashboard
- Profile and Settings

### Admin Module
- Admin Panel

### General Pages
- Home Page
- About Page
- Contact Page
- 404 Error Page

## Technologies Used

- React
- Node.js
- Supabase

## Challenges Encountered

Every member faced individual challenges while implementing their assigned features. However, the major challenge encountered by the team was integrating everyone's work into a single project. Using Git and GitHub for collaboration initially presented difficulties, but the team successfully managed the integration process.

Other challenges included:
- Integrating the frontend with the database.
- Maintaining a consistent user interface across different pages.
- Ensuring functionality worked seamlessly throughout the application.

## Conclusion

This project provided valuable experience in collaborative software development. Through the design and implementation of the system, the team gained practical knowledge of web development technologies, database integration, version control, and teamwork.

Despite the challenges encountered, the project successfully achieved its objectives by delivering a functional and user-friendly Tourism Management System.
